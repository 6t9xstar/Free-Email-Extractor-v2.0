# Free Email Extractor (Golang)

A fast and lightweight **Email Extractor built with Golang** that scans website URLs and extracts publicly available email addresses.

This tool uses **multi-threaded crawling (50–100 threads)** to achieve high-speed email extraction from websites.

⚡ Built for speed using Golang goroutines  
⚡ Open source and easy to customize  
⚡ High-performance multi-thread scraping  

---

## Features

- Extract emails from website URLs
- High-speed processing
- 50–100 concurrent threads
- Multi-threaded crawling using goroutines
- Simple CLI tool
- Export extracted emails
- Lightweight and fast
- Open-source

---

## Tech Stack

- **Language:** Golang
- **Concurrency:** Goroutines + Channels
- **HTTP Requests:** net/http
- **Regex Parsing:** regexp
